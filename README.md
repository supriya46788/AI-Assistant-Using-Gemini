# AI Assistant

This is a two-feature AI-powered web application that lets you interact with a smart assistant and also understand images using advanced AI models.

## ✨ Features

1. **AI Assistant Chat Page**
   - Ask anything and get smart, human-like responses.
   - Built using Gemini API.
   - Great for study help, general questions, suggestions, or General Knowledge.

2. **Image Description Page**
   - Upload any image and the AI will describe what it sees.
   - Useful for object detection, accessibility, or just for fun.
   - Powered by Gemini.
